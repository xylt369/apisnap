# Node.js (Express) + ApiSnap Example

This example demonstrates zero-code API regression testing for a Node.js Express backend.

## 🚀 How to Run

1. Install Express:
   ```bash
   npm install express
   ```

2. Start the server:
   ```bash
   node server.js
   ```

3. Record snapshots:
   ```bash
   apisnap record
   ```

4. Run regression tests:
   ```bash
   apisnap test
   ```
