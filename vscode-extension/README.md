# 📸 ApiSnap Pro for VS Code

> The official Visual Studio Code extension for **ApiSnap** — The Jest Snapshot for Backend APIs.

---

## ⚡ Features

- **Snapshot Explorer**: View all recorded snapshots, status codes, and execution times directly in the Activity Bar.
- **Inline Route CodeLens**: Automatic CodeLens buttons right above route definitions in Python (FastAPI/Django), Go (Gin/Fiber), Rust (Axum), and TypeScript (Express/Nest).
- **One-Click Test & Record**: Run regression tests and update snapshots without leaving your editor.
- **Pro License Manager**: Activate your $19 Lifetime Pro License to unlock all advanced features.

---

## 🚀 Usage

1. Open a project with `apisnap.toml` configured.
2. Click on the **ApiSnap** camera icon in the Activity Bar to browse your snapshots.
3. Open any route file (e.g. `main.py`, `server.go`, `routes.ts`) to see inline `📸 ApiSnap` actions.
4. Press `Cmd+Shift+P` / `Ctrl+Shift+P` and type `ApiSnap: Run Snapshot Tests`.

Run `ApiSnap: Activate Pro License Key` in the Command Palette to enter your key from [apisnap.io](https://apisnap.io).
