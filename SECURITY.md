# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ApiSnap, please send an email to `security@apisnap.io` or open a private security advisory on GitHub.

Please include:
1. A description of the vulnerability.
2. Steps or proof-of-concept to reproduce the issue.
3. Potential impact on users.

We take security seriously and will acknowledge receipt of your report within 48 hours and work on a coordinated patch.
